# Агрегатор новостей Telegram

Учебное приложение на Django для ручного добавления и просмотра новостей из Telegram-каналов.
Версия приложения — **0.0.2**.

## Образ

[kysarii/mispisit26 на Docker Hub](https://hub.docker.com/r/kysarii/mispisit26)

Тег `0.0.2` содержит сборки для `linux/amd64` и `linux/arm64`.

## Запуск

Запустите Docker Desktop и выполните в терминале:

```sh
docker pull kysarii/mispisit26:0.0.2
docker run --rm -p 8000:8000 -v telegram-news-data:/app/data kysarii/mispisit26:0.0.2
```

Откройте [http://localhost:8000/](http://localhost:8000/) в браузере.
Для остановки нажмите `Ctrl+C` в терминале запуска.

## Страницы

| Адрес | Что на странице |
| --- | --- |
| [http://localhost:8000/](http://localhost:8000/) | Главная: описание приложения, свежие новости и переходы к действиям |
| [http://localhost:8000/news/](http://localhost:8000/news/) | Лента новостей и поиск по заголовку, тексту и названию канала (просмотр) |
| [http://localhost:8000/news/1/](http://localhost:8000/news/1/) | Карточка демоновости №1: полный текст, канал, время добавления и ссылка на оригинал |
| [http://localhost:8000/news/new/](http://localhost:8000/news/new/) | Форма добавления новости: заголовок, канал, ссылка на публикацию и текст (создание данных) |
| [http://localhost:8000/action-error/](http://localhost:8000/action-error/) | Причина последнего отказа: кто, какое действие выполнял и почему оно отклонено; при первом открытии — демонстрационный пример |

При отправке пустой формы, некорректной ссылки или уже добавленной публикации
открывается страница отказа, а новость не сохраняется. Для добавления нужна ссылка
на публичную публикацию вида `https://t.me/channel/123`.

## Данные

Новости хранятся в JSON-файле `/app/data/news.json`. При первом обращении, если файл
ещё не существует, создаются три демонстрационные записи. Отдельная база данных не требуется.

Том `telegram-news-data` в команде запуска сохраняет новости после остановки,
удаления и повторного создания контейнера. Без `-v telegram-news-data:/app/data`
при запуске нового контейнера после удаления предыдущего данные вернутся к демонстрационным.
