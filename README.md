# Агрегатор новостей Telegram

Первая страница проекта на Django. Версия приложения — 0.0.1.
На странице показаны название, описание, версия и статус разработки.

## Скачивание и запуск образа из Docker Hub

Запустите Docker Desktop. В терминале из любой папки выполните:

```sh
docker pull kysarii/mispisit26:0.0.1
docker run --rm -p 8000:8000 kysarii/mispisit26:0.0.1
```

Откройте http://localhost:8000/ в браузере.
Для остановки контейнера нажмите Ctrl+C в терминале запуска.

## Сборка и запуск из исходников

В папке проекта выполните:

```sh
docker build -t telegram-news:0.0.1 .
docker run --rm -p 8000:8000 telegram-news:0.0.1
```

Откройте http://localhost:8000/ в браузере.
Для остановки контейнера нажмите Ctrl+C в терминале запуска.

Используется один контейнер на базе `python:3.13-slim`.
Django 5.2.18 устанавливается при сборке из `requirements.txt`.
HTML-шаблон отдаёт Django через маршрут `/`.
